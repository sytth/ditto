### 第二階段：專案初始化與環境設定 (Project Init & Env)
- [x] **初始化專案結構**：建立前後端目錄或 Next.js 專案架構。 (已完成)

### 第三階段：喜好設定與音樂卡片模組 (Onboarding & Music Cards)
- [x] **Onboarding 引導流程**：實作前端曲風勾選與歌手輸入 UI，並儲存至用戶喜好。 (已完成)
- [x] **iTunes 音樂搜尋 API**：接通後端 API 代理，實現輸入關鍵字搜尋 iTunes 歌曲庫。 (已完成)
- [x] **卡片管理器**：實作用戶挑選 5 首歌曲、保存並命名為今日卡片的功能。 (已完成)
- [x] **基礎播放器控制**：實作前端 Audio 播放器，固定只加載與播放前 30 秒的試聽片段。 (已完成)

### 第四階段：品味推薦與滑動配對 (Vibe Matcher & Swiping)
- [x] **品味配對演算法**：於後端實作 Jaccard 相似係數與歌手/歌曲加權的評分計算邏輯。 (已完成)
- [x] **推薦名單 API**：根據使用者的相似度評分或隨機模式，回傳 5 位未操作過的候選人。 (已完成)
- [x] **卡片滑動 UI**：實作 Tinder-like 的滑動卡片介面，包含「喜歡（右滑）」與「跳過（左滑）」的微動畫與按鈕。 (已完成)

### 第五階段：即時聊天與 48 小時倒數 (Chatroom & Countdown)
- [x] **WebSocket 基礎建設**：使用 Socket.io 建立伺服器與房間加入機制。 (已完成)
- [x] **即時文字聊天**：實作聊天室訊息發送與接收。 (已完成)
- [x] **伺服器端 48H 倒數計時**：在資料庫寫入到期時間，並在前端同步精確倒數 UI。 (已完成)
- [x] **過期自動鎖定排程**：實作定時任務，在 48 小時到期時將聊天室自動轉為唯讀狀態。 (已完成)

### 第六階段：雙盲結算與同步共聽 (Decision & Co-playing)
- [ ] **雙盲表單提交**：實作用戶點選保留/結束的 API，並在後端安全儲存。
- [ ] **解鎖/封存狀態轉移**：當雙方提交後，即時觸發聊天室永久保留（ACTIVE）或永久唯讀（ARCHIVED）邏輯。
- [ ] **同軸共聽同步播放**：實作 WebSocket 共聽邀請，並透過伺服器基準時間戳記進行雙端播放時間軸的延遲對齊。

### 第七階段：系統測試與微調 (Testing & Refinement)
- [ ] **整合與重連測試**：測試 WebSocket 斷線重連、倒數計時是否保持一致。
- [ ] **介面動態優化**：精細化卡片滑動、配對成功動畫、倒數結束彈出視窗的視覺體驗。

### 第八階段：上線準備
- [ ] **清理測試用功能**：在全系統測試完畢準備上線前，移除清除滑卡紀錄等開發階段專用的測試功能與 API。
